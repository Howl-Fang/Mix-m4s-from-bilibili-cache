# Mix-m4s-from-bilibili-cache
This project converts downloaded bilibili 'cache' video to common video. The process only mix the audio and video, renaming them, without re-encoding.
# Usage
The project requires ffmpeg installed and added in PATH.
Run the python file in the to-be-converted video folder, and the output is in `Downloads` under user's home folder, and named with the datetime conversion started. On windows, moved `Downloads` folder could also be correctly recongnized.
